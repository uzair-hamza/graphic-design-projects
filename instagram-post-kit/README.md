# Bad Caty — Instagram Post Kit

Three square posts (1080×1080, the standard Instagram square size),
all using the same Bad Caty cat mark so the feed looks consistent.

## Files
- `ig_quote.png` — funny quote post (teal background).
  "I'M NOT LAZY. I'M ENERGY EFFICIENT. — BAD CATY"
- `ig_new_video.png` — new-video announcement post (orange background).
  "NEW VIDEO! OUT NOW" + "Watch on YouTube" button + "@BadCaty".
- `ig_thank_you.png` — follower-thanks post (light background).
  "THANK YOU! FOR FOLLOWING BAD CATY — More laughs coming soon!"

## Colours
- Teal: #04ABB3
- Orange: #FF7A00
- Light background: #F5F8F8
- Dark teal text: #007878

## Fonts
- Headlines: DejaVu Sans Bold. Small lines: DejaVu Sans Regular.

## Tools
- Cat mark: AI-generated icon artwork (no text in the artwork).
- Backgrounds, layout, and all text: composed with Python (Pillow).
