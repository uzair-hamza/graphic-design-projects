# Bad Caty — Logo + Brand Identity Set

Concept: the brand mark for "Bad Caty", a funny AI cat video brand.
A cool orange cartoon cat face wearing black sunglasses, with a cheeky
tongue-out smile, on the brand teal. Friendly, bold, and readable even
at small sizes (profile pictures, watermarks).

## Files
- `badcaty_logo_main.png` (1200×1200) — main logo: cat mark + "BAD CATY"
  wordmark + "FUNNY AI CAT VIDEOS" tagline.
- `badcaty_logo_icon.png` (1024×1024, transparent corners) — simplified
  icon-only version, for avatars and app icons.
- `badcaty_logo_mono.png` (1024×1024) — monochrome version, reversed
  (white cat on black), for single-colour printing and watermarks.

## Colours
- Teal (brand background): #04ABB3
- Cat orange: #FF8C1A (approx.)
- Sunglasses black: #111111
- White: #FFFFFF
- Tagline yellow: #FFDC78

## Fonts
- Wordmark/tagline: DejaVu Sans Bold (preview build). For a final brand
  kit, use any rounded bold sans (e.g. Baloo 2 Bold, Fredoka Bold).

## Tools
- Cat artwork: AI-generated icon artwork (no text in the artwork).
- All text, layout, and the monochrome version: composed with Python
  (Pillow), so every word is crisp and spelled correctly.
