# Infographic — How AI Learns

A portrait poster (1080×1920) that explains machine learning in 5
simple steps, in reading order from top to bottom, with a numbered
badge, a flat icon, and one short line per step.

## The 5 steps
1. DATA — "AI collects lots of examples to learn from."
2. TRAINING — "It studies the examples again and again."
3. PATTERN — "It finds patterns hidden in the data."
4. PREDICTION — "It guesses the answer for new examples."
5. IMPROVEMENT — "It learns from mistakes and gets better."

Footer: "AI EXPLAINED SIMPLY".
