# Graphic Design Projects

Portfolio graphic design work by **Muhammad Uzair Hamza** — BSc Computer Systems Engineering student, UET Peshawar.

## Projects

- **logo-brand-identity** — Logo + brand identity set for "Bad Caty" (main logo, icon-only version, monochrome version).
- **youtube-thumbnails** — 3 YouTube thumbnails (1280×720): Bad Caty, Dragon Dost story, AI explainer.
- **instagram-post-kit** — 3 square Instagram posts (1080×1080): quote post, new-video announcement, thank-you post.
- **infographic** — "How AI Learns" in 5 simple steps (1080×1920 poster).
- **figma-ui** — Plant Disease Detector mobile app UI: Home, Camera/Upload, Diagnosis Result, History screens, with a full Figma rebuild spec.

## Tools

Background artwork generated with AI (no text); all text composed with PIL so every word is crisp and correctly spelled. Each project folder has its own README with concept, colors, and fonts.
